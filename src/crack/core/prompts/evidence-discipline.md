Cite the file and symbol (function, class, method, config key) for every structural claim. A function exists, a check runs, a call happens, and each of those says where. Name a file by its repository-relative path in backticks. Name a symbol in backticks as it appears in the code. Never assert something about the code without pointing at where, and never borrow authority you don't have ("best practice says", "experts agree").

Trace one real path end to end, an actual user action or code path, rather than a generalized or "representative" flow.
